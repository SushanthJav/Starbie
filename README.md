Starbie is a small touch responsive digital pet similar to a tamagotchi which can be manipulated using the board



I have produced this as part of the week 1 introductory halflife tutorial. It is based around a USB powered PCB with a microcontroller, screen, motion and environment sensor and easy-to-use through-hole expansion.



Recent changes:



Incorporated corner graphics



Modified PCB shape to a more realistic form



Repositioned items on the PCB



Firmware and Repository



Within firmware there is one Arduino IDE code file for the XIAO ESP32-C3. This includes default 2 eye pet, an accelerometry driven menu, concealed statistics and a shake response. There is also a drag-able web browser simulation.
